# Objetivos del Proyecto

## Objetivo General

Desarrollar y desplegar un modelo de inteligencia artificial, basado en Ollama, capaz de analizar signos vitales, síntomas clínicos y antecedentes médicos para generar clasificaciones de triaje precisas y recomendaciones de prioridad de atención que optimicen la gestión de emergencias.

## Objetivos Específicos
- Recopilar y procesar un conjunto de datos de alta calidad que incluya información sobre signos vitales, síntomas clínicos, antecedentes médicos, diagnósticos y tiempos de atención en servicios de emergencia.
- Desarrollar una arquitectura de modelo de lenguaje grande (LLM) personalizada que pueda comprender y analizar información clínica para generar clasificaciones de triaje (escala de urgencia), utilizando Ollama como base.
- Diseñar una interfaz intuitiva que permita a profesionales de salud (médicos, enfermeros, técnicos) interactuar con el modelo de forma sencilla y obtener recomendaciones claras y accionables en contextos de alta presión.
- Implementar mecanismos para evaluar el desempeño del modelo mediante métricas clínicas relevantes (sensibilidad, especificidad, valor predictivo) y realizar ajustes para mejorar su precisión y utilidad.
Asegurar que el sistema respete protocolos éticos y regulaciones de privacidad de datos médicos sensibles.
